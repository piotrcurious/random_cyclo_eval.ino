# Theory of Operation: Corrected Signal Converger

## Overview
The system aims to approximate an input periodic signal $x[t]$ using a synthetic signal $y[t]$ generated by a Linear Feedback Shift Register (LFSR) and a Cyclotomic Digital Filter.

## Components

### 1. Linear Feedback Shift Register (LFSR)
An LFSR generates a pseudorandom bit sequence. It is defined by its state and its feedback polynomial (taps).
For an 8-bit LFSR, the state $S \in [1, 255]$.
The output at time $t$ is $b[t] = S_t \& 1$.

### 2. Cyclotomic Digital Filter
A cyclotomic polynomial $\Phi_n(z)$ is used as the transfer function of a FIR filter.
For $n=16$, $\Phi_{16}(z) = z^8 + 1$.
The filter coefficients $c_i$ are the coefficients of $\Phi_n(z)$.
The filtered output is:
$y[t] = \sum_{i=0}^{D} c_i \cdot b[t-i]$

Since $\Phi_n(z)$ coefficients are typically in $\{-1, 0, 1\}$, this filter is extremely efficient to implement on a microcontroller.

### 3. Convergence Mechanism
The system seeks a "representation" of the input signal by finding the optimal LFSR taps and initial state.
Instead of an exhaustive search, the system uses a randomized search with error tracking:
1. Sample the input signal into a buffer $B_{in}$.
2. Generate a candidate output $B_{out}$ using current LFSR parameters.
3. Calculate the Mean Squared Error (MSE) between $B_{in}$ and $B_{out}$.
4. If MSE is lower than the best recorded error, keep the current LFSR parameters.
5. Periodically mutate the LFSR taps or reset the state to explore the search space.

## Mathematical Correctness
* **Cyclotomic Polynomials**: We use $\Phi_{16}(x) = x^8 + 1$ or $\Phi_8(x) = x^4 + 1$.
* **LFSR**: We use a standard Galois LFSR implementation.
* **Scaling**: Since the LFSR output is bits (0/1) and the filter coefficients are small integers, the output $y[t]$ will be small. We scale $y[t]$ to the range [0, 255] for PWM output and comparison with `analogRead`.
